## 这本书带你做什么

写给**不做算法、想从零系统学一遍 LoRA 微调的开发者**：后端、前端、客户端、数据或测试开发都可以。不需要机器学习背景，只要会用终端、能读 Python。你会在一张 RTX 4090 上亲手走完：下载开源模型 → QLoRA 微调 → 保存与重载 → 合并导出 → vLLM 部署成 OpenAI 兼容 API → 从自己电脑调用和压测。每一步都说明显存花在哪里、文件在哪里、怎样确认这一步真的成功了。

## 为什么用“小学科学问答”练习

孩子问“月亮怎么变弯了”，回答之后又说“我没听懂”，或者猜“是不是被地球挡住了”。这类对话风格鲜明，微调前后的变化容易看出来，也方便你判断模型有没有乱编。

`data/dataset.json` 保存 60 张事实卡和 600 段合成对话：**500 段训练、50 段验证、50 段测试**，全部是待审核草稿，用来学流程足够。

## 阅读顺序

目标与准备 → 必要概念 → 训练数据 → GPU 准备 → Notebook 训练（默认 1 个 Epoch，约 72 步）→ 部署与调用 → 效果评估。按目录顺序读就是操作顺序；每章开头都写明本章做什么、需要准备什么、做完得到什么。成本、排错和开发者参考放在最后，遇到问题时查。

没有 GPU 或机器学习背景也没关系：第 0 章先讲清楚整件事的全貌和需要准备的东西，第 1 章用开发者熟悉的类比（数据库、Git、Web 服务）解释所有用到的概念。

训练结束后，你会拿到训练完成记录、loss 曲线、adapter、可部署的完整模型、一个在跑的 vLLM 服务，以及自己测出的延迟和吞吐数字。
