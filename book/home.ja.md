## この本で取り組むこと

本書は、**アルゴリズムを専門としておらず、LoRA ファインチューニングをゼロから体系的に学びたい開発者**のために書かれています。バックエンド、フロントエンド、クライアント、データ、テストのいずれの開発者でも歓迎です。機械学習の知識は不要で、ターミナルが使えて Python が読めれば十分です。1 枚の RTX 4090 上で、次の流れを自分の手で一通り体験します：オープンソースモデルのダウンロード → QLoRA ファインチューニング → 保存と再読み込み → マージとエクスポート → vLLM で OpenAI 互換 API としてデプロイ → 自分のパソコンから呼び出しと負荷テスト。各ステップでは、VRAM が何に使われるのか、ファイルがどこにあるのか、そのステップが本当に成功したことをどう確認するのかを説明します。

## なぜ「小学校の理科 Q&A」で練習するのか

子どもが「月亮怎么变弯了」（「月はどうして欠けて見えるの？」）と尋ね、答えを聞いたあとに「我没听懂」（「よくわからなかった」）と言ったり、「是不是被地球挡住了」（「地球に隠されているの？」）と推測したりします。こうした会話ははっきりした特徴を持つため、ファインチューニング前後の変化が見えやすく、モデルがでたらめを言っていないかも判断しやすくなります。

`data/dataset.json` には 60 枚のファクトカードと 600 件の合成会話が収められています：**学習用 500 件、検証用 50 件、テスト用 50 件**。すべてレビュー待ちのドラフトですが、ワークフローを学ぶには十分です。

## 読む順番

目標と準備 → 必要な概念 → 学習データ → GPU の準備 → Notebook での学習（デフォルトは 1 エポック、約 72 ステップ）→ デプロイと呼び出し → 評価。目次の順に読めば、そのまま作業の順番になります。各章の冒頭には、その章で何をするか、何を準備する必要があるか、終えると何が得られるかを書いています。コスト、トラブルシューティング、開発者向けリファレンスは最後にまとめてあるので、問題にぶつかったときに参照してください。

GPU や機械学習の経験がなくても大丈夫です。第 0 章ではまず全体像と準備すべきものを説明し、第 1 章では開発者になじみのあるたとえ（データベース、Git、Web サービス）を使って、登場するすべての概念を説明します。

学習が終わると、学習完了の記録、loss 曲線、adapter、デプロイ可能な完全なモデル、稼働中の vLLM サービス、そして自分で計測したレイテンシとスループットの数値が手元に残ります。
