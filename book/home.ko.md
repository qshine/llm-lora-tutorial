## 이 책에서 함께 할 일

이 책은 **알고리즘을 다루지 않지만 LoRA 파인튜닝을 처음부터 체계적으로 배우고 싶은 개발자**를 위해 썼습니다. 백엔드, 프런트엔드, 클라이언트, 데이터, 테스트 개발자 모두 환영합니다. 머신러닝 배경지식은 필요 없고, 터미널을 다룰 줄 알고 Python을 읽을 수 있으면 됩니다. RTX 4090 한 장으로 다음 과정을 직접 따라 합니다: 오픈 소스 모델 다운로드 → QLoRA 파인튜닝 → 저장과 다시 불러오기 → 병합과 내보내기 → vLLM으로 OpenAI 호환 API로 배포 → 내 컴퓨터에서 호출하고 부하 테스트하기. 각 단계마다 VRAM이 어디에 쓰이는지, 파일이 어디에 있는지, 그 단계가 정말 성공했는지 어떻게 확인하는지를 설명합니다.

## 왜 "초등학교 과학 질의응답"으로 연습할까

아이가 “月亮怎么变弯了”(“달은 왜 휘어 보여요?”)라고 묻고, 답을 들은 뒤 “我没听懂”(“잘 모르겠어요”)라고 하거나 “是不是被地球挡住了”(“지구에 가려진 거예요?”)라고 추측합니다. 이런 대화는 스타일이 뚜렷해서 파인튜닝 전후의 변화가 쉽게 보이고, 모델이 지어낸 말을 하는지도 판단하기 쉽습니다.

`data/dataset.json`에는 사실 카드 60장과 합성 대화 600개가 들어 있습니다: **학습용 500개, 검증용 50개, 테스트용 50개**이며, 모두 검토 대기 중인 초안이지만 워크플로를 익히기에는 충분합니다.

## 읽는 순서

목표와 준비 → 필수 개념 → 학습 데이터 → GPU 준비 → Notebook 학습(기본 1 에폭, 약 72스텝) → 배포와 호출 → 평가. 목차 순서대로 읽으면 그대로 작업 순서가 됩니다. 각 장의 첫머리에는 그 장에서 무엇을 하는지, 무엇을 준비해야 하는지, 끝나면 무엇을 얻는지가 적혀 있습니다. 비용, 문제 해결, 개발자 레퍼런스는 맨 뒤에 있으니 문제가 생겼을 때 찾아보세요.

GPU나 머신러닝 배경지식이 없어도 괜찮습니다. 0장에서 먼저 전체 그림과 준비할 것을 설명하고, 1장에서는 개발자에게 익숙한 비유(데이터베이스, Git, 웹 서비스)로 사용되는 모든 개념을 설명합니다.

학습을 마치면 학습 완료 기록, loss 곡선, 어댑터, 배포 가능한 전체 모델, 실행 중인 vLLM 서비스, 그리고 직접 측정한 지연 시간과 처리량 수치를 손에 넣게 됩니다.
